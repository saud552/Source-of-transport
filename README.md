# نظام البوتات الثلاثة المتكاملة

## نظرة عامة
هذا المشروع يتكون من ثلاثة بوتات تعمل بشكل مترابط لإدارة حسابات التليجرام ونقل الأعضاء:

1. **بوت إضافة الحسابات** (`add.py`) - تسجيل وإدارة حسابات التليجرام
2. **بوت التخزين** (`storage.py`) - تخزين أعضاء المجموعات
3. **بوت النقل** (`transf.py`) - نقل الأعضاء المخزنين إلى مجموعات جديدة

## الميزات الرئيسية

### بوت إضافة الحسابات
- تسجيل حسابات جديدة باستخدام TDLib
- إدارة فئات الحسابات
- تشفير البيانات الحساسة
- واجهة سهلة الاستخدام

### بوت التخزين
- التخزين المخفي (من الرسائل)
- التخزين الظاهر (من قائمة الأعضاء)
- إدارة المجموعات المخزنة
- تصدير البيانات

### بوت النقل
- اختيار المجموعة المصدر
- اختيار فئة الحسابات
- إدخال المجموعة الهدف
- نقل الأعضاء بذكاء
- تتبع التقدم والإحصائيات

## التثبيت والتشغيل

### المتطلبات
```bash
pip install python-telegram-bot
pip install tdlib
```

### تشغيل البوتات
```bash
# تشغيل جميع البوتات
python main.py

# أو تشغيل كل بوت منفصل
python add.py
python storage.py
python transf.py
```

## الاستخدام

### 1. إضافة الحسابات
1. ابدأ بوت إضافة الحسابات
2. استخدم `/start` لبدء العملية
3. اختر "إضافة حساب جديد"
4. أدخل رقم الهاتف
5. أدخل كود التحقق
6. اختر فئة الحساب

### 2. تخزين الأعضاء
1. ابدأ بوت التخزين
2. استخدم `/start` لبدء العملية
3. اختر نوع التخزين (مخفي أو ظاهر)
4. أدخل رابط المجموعة
5. اختر فئة الحسابات
6. ابدأ التخزين

### 3. نقل الأعضاء
1. ابدأ بوت النقل
2. استخدم `/start` لبدء العملية
3. اختر المجموعة المصدر
4. اختر فئة الحسابات
5. أدخل رابط المجموعة الهدف
6. ابدأ النقل
